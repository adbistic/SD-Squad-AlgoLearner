# SD-Squad: AlgoLearn

**AlgoLearn** is a desktop app that teaches algorithms step by step.
Students go through three levels (**Easy**, **Intermediate** and **Hard**). Each level has short lessons
with explanations, Java code and complexity, and ends with a **milestone quiz**.
Passing a quiz (60% or more) unlocks the next level.

Built in **Java** (JavaFX) as a team project for our Git & teamwork course.

## Levels

| Level | Lessons |
|---|---|
| 🟢 Easy | Linear Search & Big-O · Bubble Sort · Selection Sort |
| 🟡 Intermediate | Binary Search · Insertion Sort · Merge Sort |
| 🔴 Hard | Quick Sort · Graphs: BFS & DFS · Dijkstra's Shortest Path |
